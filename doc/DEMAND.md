## 二、参赛作品要求

参赛作品需围绕 Agent Economy（智能体经济）展开，方向包括但不限于：

- 构建代表 Agent 的 Skill（可被 Agent 调用执行）
- 开发赋能 Agent 的应用（交易、支付、协作、服务分发等）
- 体现 Agent 在链上真实可执行能力（调用 API、管理资产、执行链上操作）

## 六、可选参赛项目方向清单（可直接立项）

以下是适配本次活动的可选项目方向，优先选择“可演示、可复现、可量化结果”的方案：

### A. 交易类 Agent（高匹配 Bitget Wallet 赛道）

- Meme 币自动交易 Agent（策略开关、止盈止损、风控上限）
- 钱包信号跟单 Agent（跟踪指定地址并执行条件化交易）
- 多策略轮换 Agent（趋势、均值回归、事件驱动）

### B. Agent 协作与服务市场

- 多 Agent 协同执行框架（研究 Agent + 执行 Agent + 风控 Agent）
- Agent Service Marketplace（发布/订阅可调用的链上服务）
- Agent 任务路由系统（根据费用、速度、成功率智能派单）

### C. 支付与资产管理 Agent

- 自动化资金管理 Agent（分账、定投、自动再平衡）
- 链上支付执行 Agent（条件触发付款、预算控制、审计记录）
- 收益聚合 Agent（在风险参数下进行收益策略调度）

### D. Solana Mobile 与用户体验方向

- 面向移动端的钱包内 Agent 助手
- 移动端语音/自然语言下单与资产查询 Agent
- 移动端一键策略模板（新手可用，专家可配置）

## 七、建议的最小可交付标准（MVP）

建议至少满足以下最低标准，以提升获奖和传播概率：

- 有公开代码仓库，能运行并复现核心功能
- 有在线演示或录屏，能展示真实链上交互
- 有可量化结果（收益、成功率、延迟、成本等）
- 有风险控制机制（权限、限额、失败回滚、异常处理）
- 有清晰提交材料（X Article + Quote RT 完整达标）
